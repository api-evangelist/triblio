## What it does

- Account-based advertising across display and social
- Intent-driven audience segmentation, fed by Bombora Company Surge (weekly),
  G2 intent (nightly), first-party web visits, and Foundry's own publisher network
- Website personalization for targeted accounts
- A Smart Score that ranks accounts from behavioral signals
- Sales acceleration, sold by Foundry as "Foundry Sales Acceleration, powered by Triblio"

## Integration model — read this before looking for an API

Triblio integrates by **consuming other vendors' APIs**, not by exposing one of its
own. Credentials for third-party services are pasted into the platform's
Setup > "Web Sites & API" tab:

- Salesforce — uses the Salesforce REST API, authorized in a two-step flow
- Marketo — uses Marketo's REST API
- SugarCRM — requires creating OAuth keys inside SugarCRM
- Microsoft Dynamics 365
- HubSpot — a listed marketplace app, bidirectional list/audience sync
- G2 — a G2 API key entered in the Setup tab
- Bombora, LinkedIn Campaign Manager, Google Analytics, Slack

Do not mistake any of these for a Triblio API. There is no `api.triblio.com`; that
host has never resolved and has no record in the Internet Archive.
